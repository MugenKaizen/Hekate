# Hekate v0.1.0-beta.1 — Cross-harness orchestration

This is Hekate's first tagged beta release. It packages the portable workflow,
conservative update system, and a new cross-harness job controller for
long-running agent tasks.

## Highlights

- Delegate from any shell-capable parent agent to Claude Code, pi, OpenCode,
  Codex CLI, Gemini CLI, Aider, or a custom harness.
- Choose model and effort during workflow initialization, per developer, or per
  run.
- Run tasks in the background and manage them with persistent job IDs, status,
  logs, timeout-aware waiting, results, and safe stop operations.
- No MCP server, resident daemon, runtime package manager, or pairwise adapter
  matrix.
- Claude Code includes `/harness` and the `harness-orchestrator` custom agent.
- Existing installations receive the feature through migration 003.
- POSIX and PowerShell entrypoints are included.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/MugenKaizen/Hekate/v0.1.0-beta.1/install.sh | sh
```

PowerShell 5.1+:

```powershell
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
& ([scriptblock]::Create((Invoke-RestMethod https://raw.githubusercontent.com/MugenKaizen/Hekate/v0.1.0-beta.1/install.ps1)))
```

Pinning the tag is recommended for reproducible installations.

## Upgrade

From an existing Hekate installation:

```sh
curl -fsSL https://raw.githubusercontent.com/MugenKaizen/Hekate/v0.1.0-beta.1/update.sh \
  | sh -s -- --target=. --ref=v0.1.0-beta.1
```

The updater applies `003-add-cross-harness-orchestration` and preserves local
changes using the existing backup/`.new` review behavior.

## Getting started

After initialization:

```sh
.workflow/bin/hekate-agent doctor
.workflow/bin/hekate-agent config use pi \
  --model openai-codex/gpt-5.4 --effort high
job_id=$(.workflow/bin/hekate-agent run --task-file /tmp/task.md)
.workflow/bin/hekate-agent wait "$job_id" --timeout 3600
.workflow/bin/hekate-agent result "$job_id"
```

See the [orchestration guide](https://github.com/MugenKaizen/Hekate/blob/v0.1.0-beta.1/docs/orchestration.md)
for configuration, custom harnesses, lifecycle commands, and the safety model.

## Beta notes

- Harness flags and model identifiers are upstream-version-specific. Run
  `hekate-agent doctor` after upgrading a CLI.
- The PowerShell runner is included, but should be smoke-tested on Windows
  before publishing; the broadest current testing is on POSIX systems.
- Job metadata and orchestration configuration may evolve before Hekate 1.0.

Please report reproducible issues with the harness name/version, command used,
job status, and redacted stderr log.
